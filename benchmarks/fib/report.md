# fib — 递归 Fibonacci（整数基准）

## 说明
递归计算 `fib(40)`，测量函数调用与 32 位整数运算性能。四路采用相同的朴素递归算法。

## 规模与结果
- 输入：`n = 40`
- 校验结果（四路一致）：`result=102334155`

## 性能（纯计算时间，3 次取中位数，越低越好）

| 实现 | 耗时 (ms) | 相对 C |
|------|----------:|-------:|
| C (cc -O2) | 285 | 1.00× |
| JavaScript (Node v24) | 788 | 2.76× |
| **as3compiler** (→ C → cc -O2) | 287 | 1.01× |
| 原生 AS3 (AIR/mxmlc) | 3572 | 12.53× |

## 分析
- **as3compiler 与 C 几乎一致（1.01×）**：生成的 C 递归经 `-O2` 后与手写 C 等价，
  验证了「只翻译、优化交给 C 编译器」的路线在调用密集型整数代码上不损失性能。
- **JS 2.76×**：V8 对未优化的递归调用仍有逐调用开销。
- **原生 AS3 12.53×**：AVM2 虚拟机的函数调用与 `int` 装箱/拆箱是主要开销。

## 计时口径
- 四路均内部计时纯计算（C: `clock_gettime` / JS: `hrtime` / as3compiler: `Date.getTime` / 原生 AS3: `getTimer`）。
- 原生 AIR 的 `adl` 启动开销（约 2.6s）不计入。
