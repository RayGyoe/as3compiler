# mandelbrot — Mandelbrot 集合计数（浮点内层循环基准）

## 说明
对 `size=1500` 的像素网格做 Mandelbrot 逃逸判定（每像素最多 50 次迭代），
统计收敛点的数量。测量纯 `double` 算术与紧内层循环性能，无任何对象分配。

## 规模与结果
- `size = 1500`（1500×1500 像素，每像素 ≤50 次迭代）
- 校验结果（四路一致）：`result=894105`

## 性能（纯计算时间，3 次取中位数，越低越好）

| 实现 | 耗时 (ms) | 相对 C |
|------|----------:|-------:|
| C (cc -O2) | 95 | 1.00× |
| JavaScript (Node v24) | 124 | 1.31× |
| **as3compiler** (→ C → cc -O2) | 94 | 0.99× |
| 原生 AS3 (AIR/mxmlc) | 355 | 3.74× |

## 分析
- **as3compiler 0.99×**：分配自由的纯浮点循环，生成的 C 与手写 C 无差别。
- **JS 1.31×**：V8 已能较好优化数值循环，但仍略慢于 AOT。
- **原生 AS3 3.74×**：AS3 的 `Number`（double）运算本身不算慢，循环控制与变量
  存取开销拉大了差距。

## 计时口径
- 四路均内部计时纯计算（C: `clock_gettime` / JS: `hrtime` / as3compiler: `Date.getTime` / 原生 AS3: `getTimer`）。
- 原生 AIR 的 `adl` 启动开销（约 2.6s）不计入。
