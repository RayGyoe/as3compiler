WASM 声明式导出 · [WasmExport]

与命令行 --export 不同，[WasmExport] 把导出标记写在 .as 源码里：编译时自动收集、注入链接器 --export，并在 .wasm 旁生成 .exports.json 记录调用契约。跨包 / 命名空间时无需手记长符号名（如 mathlib_Calc_twice），直接用 [WasmExport("别名")] 指定 JS 调用名。

源码（export-meta.as）

package mathlib {
    [WasmExport]                     // 顶层函数：JS 名 = C 符号名 add
    function add(a:int, b:int):int { return a + b; }

    [WasmExport("multiply")]         // 顶层函数：别名 multiply → C 符号 mul
    function mul(a:int, b:int):int { return a * b; }

    class Calc {
        [WasmExport("twice")]        // 静态方法：别名 twice → C 符号 mathlib_Calc_twice
        public static function twice(a:int):int { return a * 2; }
    }
}
点击后加载 export-meta.wasm，读取导出表并直接调用三个声明式导出函数。
